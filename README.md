# MCPs for Marketers — The Complete CMO’s Field Guide

Created by Barbara Basquill. A no-jargon, visual, independent guide to MCP and connected AI for B2B marketing leaders.

## What's included

- `index.html`: conceptual guide, visual diagrams, use cases, permissions
- `connect-claude.html`: easy-to-follow Claude connector walkthrough
- `connect-chatgpt.html`: app connection walkthrough for ChatGPT
- `starter-project.html`: safe introductory marketing exercise and glossary
- `styles.css`: same editorial design language as the original CMO’s field guide
- `guide.js`: copy-prompt interaction
- `assets/mcp-guide-cover.png`: dedicated MCP book-cover artwork (no BS Detector cover)

## Publish with GitHub Pages (no terminal)

1. Create a **public** repository named `mcp-for-marketers-guide`, without initializing README.
2. Unzip the package. Upload the **contents** of this folder to repository root. Preserve the `assets/` folder. Commit.
3. In Settings → Pages, choose **Deploy from a branch**, `main`, `/(root)` and Save.
4. After a successful Pages deployment, visit `https://barbarabasquill.github.io/mcp-for-marketers-guide/`.

## About the walkthrough

Claude UI: https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities
ChatGPT UI: https://help.openai.com/en/articles/11487775-connected-apps-in-chatgpt

Features depend on the app, permissions, workspace and account. Connecting a supported app is not the same as building your own MCP server. This is an independent educational guide.
