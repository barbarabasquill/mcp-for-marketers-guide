What are these files?

A CSV is a simple spreadsheet file. Download both, then open Claude or ChatGPT and attach both CSVs to one conversation using its file-upload control. You do not need to create an MCP connection for this practice activity.

Look closely: Some accounts match, some opportunities existed before the webinar, one attendee did not attend, and some account details are incomplete or ambiguous. That is intentional.

Important: Uploading a CSV file is not an MCP connection.

Uploading CSV files to Claude or ChatGPT is a file-analysis exercise. It helps you learn how to ask questions, analyze information, and verify results.

Start with sample files to practice. Then, when you’re ready, use approved MCP-connected systems (where supported) to retrieve information directly from authorized applications.

COPY THE EXERCISE

Ask a better question.

I attached two fictional CSV files: webinar-attendees.csv and crm-opportunities.csv. Match attendees to opportunities using CRM account ID first, and only consider company domain as secondary supporting evidence. Show attendee name, attendance status, matched account, opportunity ID, opportunity stage, opportunity creation date, match evidence and any uncertainty. Do not assume webinar attendance caused or influenced an opportunity. Highlight opportunities created before the webinar, no-shows, missing account IDs and ambiguous domains. Do not invent records or take any actions. Summarize findings for human review.

Using a real connector? If you’ve connected an authorized application, replace “these fictional lists” with the approved data sources you’ve enabled in Claude or ChatGPT. Ask the AI to cite the specific records it used, including source links or record IDs, so you can verify the results yourself.

What success looks like: You get a table grounded in the attached CSVs with opportunity IDs and clear flags for ambiguous or pre-existing opportunities. These fictional files cannot prove attribution or influence.

BEFORE YOU TRUST AN AI ANSWER

Did AI Get It Right?

AI can sound certain even when it gets something wrong. This is your quick, human review before you use its answer in a campaign report or make a business decision.

Here's an example:
“25 webinar attendees became sales opportunities, generating $450,000 in pipeline.”

That sounds impressive. But is it true? A webinar attendee isn't automatically a sales opportunity. You need real records showing what happened.

Why this matters: Even when an AI assistant accesses real data through a connector, it can reach the wrong conclusion. If it says someone “became pipeline,” ask for the opportunity record and evidence of the relationship. Attendance alone does not prove pipeline influence.
THE CMO RULE

Connections give AI access to information. They don't guarantee its interpretation is correct. You make the final call.

PLAIN ENGLISH

Words worth knowing.

MCP
A shared set of rules that lets AI applications use outside tools.
Connector
A configured link between an assistant and a particular service.
MCP server
Software offering specific tools, resources or prompts to an MCP client.
Client
The part of the AI application that communicates with the MCP server.
Permissions
Rules about what the connection may read or do.
Read-only
Can look up information but not change records.
API
A way one application requests information or work from another.
OAuth
A common sign-in and authorization method that avoids giving a connector your password directly.
Tool
A specific capability, like “search records.”
Human approval
A person reviews a proposed action before it happens.
