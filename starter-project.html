YOUR FIRST PRACTICAL PROJECT

From connected data
to a useful answer.

Goal: identify which webinar attendees from target accounts deserve a sales review—without giving AI permission to send messages or change CRM records.

For a first attempt, you can use two small fictional CSV files instead of connecting real systems. When your organization approves suitable connectors, you can repeat the exercise using permitted data.

GET READY

What you'll need.

  • A list of webinar attendees with account names.
  • A list of target accounts or CRM opportunity records.
  • A clear matching rule, such as company domain plus account ID.
  • Permission to use any real data; fictional examples are best for learning.
    • A useful difference: Uploading CSV files to Claude is a file-analysis exercise, not an MCP connection. Use the files first to learn the question, then use approved MCP-connected systems if available.

    COPY THE EXERCISE

    Ask a better question.

    “Compare these fictional webinar attendee and target-account lists. Find possible matches and show the matching evidence. Make a table with attendee, account, matching fields, confidence and missing information. Do not invent opportunities or send messages. Flag uncertain matches for human review.”

    If you are using a real authorized connector, replace “these fictional lists” with the approved sources you have enabled and ask Claude to cite individual records.

    CHECK THE ANSWER

    Would you trust it?

    Before using the results, review the checklist:

    If the result says an attendee “became pipeline,” ask for the opportunity record, relationship evidence and attribution definition. Attending a webinar alone does not prove pipeline influence.

    PLAIN ENGLISH

    Words worth knowing.

    MCP
    A shared set of rules that lets AI applications use outside tools.
    Connector
    A configured link between an assistant and a particular service.
    MCP server
    Software offering specific tools, resources or prompts to an MCP client.
    Client
    The part of the AI application that communicates with the MCP server.
    Permissions
    Rules about what the connection may read or do.
    Read-only
    Can look up information but not change records.
    API
    A way one application requests information or work from another.
    OAuth
    A common sign-in and authorization method that avoids giving a connector your password directly.
    Tool
    A specific capability, like “search records.”
    Human approval
    A person reviews a proposed action before it happens.
