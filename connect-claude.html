A BEGINNER WALKTHROUGH

Connect one app.
One click at a time.

We’ll use Claude’s built-in Connectors Directory. You don’t need to write code or open a terminal.

Before you begin: Sign in to Claude. Choose a work-approved app you have permission to access. The exact apps, buttons and features shown can vary by account, plan and organization policy.

THE EASY ROUTE

Find the connector.

  1. Open Claude.

    Go to claude.ai and sign in.

  2. Open “Customize.”

    Look in Claude's sidebar and choose Customize → Connectors. If you’re already in a chat, you can also click the + near the message box, choose Connectors → Manage connectors, and open the directory.

  3. Browse the directory.

    Click the + next to Connectors. Choose an application your organization permits.

  4. Read before connecting.

    Check what the connector can access and whether it can take actions, not just read data.

  5. Click “Connect” or “Install.”

    Follow the sign-in screens for that application. Only approve the access you understand and need.

  6. Enable it in a chat.

    Open a Claude conversation, click +, find Connectors, and enable the one you want to use.

Labels can change as Claude updates its interface. These steps follow Claude's official connector help, reviewed October 2026.

CONFIRM IT WORKS

Try a safe first question.

Ask for something small and read-only. For example, with an approved document connector:

“Find one document I’m allowed to read about our latest marketing campaign. Tell me its title and source. Don’t change anything.”

Before trusting the result

  • Did Claude use the connector you expected?
  • Can you open and verify the source?
  • Did it respect your access permissions?
  • Did it avoid editing, exporting or sharing anything?

How to disconnect

Return to Customize → Connectors. Find the connected service and choose the disconnect option. You can also review or adjust its permissions and access settings there. For company-wide access, ask your administrator.

FOR THE CURIOUS

What's a custom MCP connection?

A directory connector is the simplest path. A custom remote MCP connector is different: someone provides a specific MCP server URL, and the server exposes tools to Claude. You should only add a custom address from a source you trust.

  1. Get a trusted MCP server URL.

    Your company or vendor must provide an actual supported server endpoint—not just a normal website homepage.

  2. Go to Customize → Connectors.

    Choose the option to add a custom Web connector. The wording can vary by plan.

  3. Enter its name and server URL.

    Follow authentication prompts, inspect requested permissions, and confirm.

  4. Test with a small, read-only request.

    Verify where the answer came from before doing more.

Not the same thing: A regular webpage is not automatically an MCP server. Claude Desktop extensions are another path for local computer tools, with separate installation steps.
